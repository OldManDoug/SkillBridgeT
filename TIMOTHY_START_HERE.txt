TIMOTHY - TRY THE QUIZ

1. Follow README.md to set up MySQL and run the website.
   Replace YOUR_USER and YOUR_PASSWORD with your own MySQL details.
2. Run database/quiz_example.sql in MySQL Workbench.
   It adds one example course and quiz. Running it again adds no duplicate.
3. Sign in as a Member. Open Courses, select SQL Quiz Practice and enrol.
4. Open My Courses, select the quiz, then Start or resume quiz.
5. Answer both questions and submit. Check the result and attempt history.
   SELECT + INSERT scores 4/4. Only SELECT correct scores 3/4 (below the 80% pass mark).
   Admins can also open Admin > Quizzes > Preview.
